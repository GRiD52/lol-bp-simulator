# 英雄联盟 BP 模拟器（静态站）

一个纯前端、双击即用的 LoL 赛事 BP 模拟小游戏：选队 → 按职业规则 BP → 调整分路 → 阵容分析 → 全程模拟解说 → 系列赛总结。

## 打开方式

直接双击 `index.html` 即可（数据与资源全部本地，无需联网、无需构建、无需 ES module）。

如果浏览器对本地文件有限制，也可以起一个静态服务：

```
cd D:\deepseek\bp
python -m http.server 8000      # 或 npx serve .
# 打开 http://127.0.0.1:8000/
```


## 自己部署一份

纯静态站，任何静态托管都能放，**不用改任何代码**（所有资源路径都是相对的，放在子路径下也能跑）。

### 方式 A：GitHub Pages

```
cd D:\deepseek\bp
git init -b main
git add .
git commit -m "LoL BP simulator"
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

然后到仓库 **Settings → Pages → Build and deployment → Source: Deploy from a branch → main / (root)**。
注意在仓库根目录放一个空的 `.nojekyll` 文件，否则 GitHub 会用 Jekyll 处理整个站点（本项目 796 个文件、43MB，Jekyll 构建会失败或卡十几分钟）。

> 首次 push 会要求登录：Windows 上会弹浏览器授权，或者用 GitHub 的 Personal Access Token 当密码。
> `_tools/` 是开发脚本（抓数据、跑自检、截图），已在 `.gitignore` 里排除，不会上传。

### 方式 B：Netlify Drop（没账号也能 30 秒上线）

1. 打开 <https://app.netlify.com/drop>；
2. 把 `D:\deepseek\bp` 文件夹（或上面的 zip 解压后的文件夹）整个拖进去；
3. 拿到 `https://xxx.netlify.app/` 就能直接发给朋友。

免费额度足够个人玩；想绑自己的域名在 Netlify 后台加即可。Vercel / Cloudflare Pages 同理，选「静态站点、无构建命令、输出目录 `/`」。

### 注意

- 玩家在自己浏览器里改的数据（数值、头像、自建队伍）存在 **localStorage**，跟站点域名绑定：换域名/换浏览器就看不到了，也不会同步给别人。
- 更新版本后如果朋友还看到旧的界面，让他强制刷新（`Ctrl+F5`）；图片有浏览器缓存，一般会自动更新。

## 玩法流程

1. **选队**：左右各选一队（含你自己新建的队伍），蓝红方可交换，选 BO3 / BO5，可选无畏征召、硬核禁选继承、每手倒计时；每个位置都能直接在名单里换人（替补、自由选手池里的自建选手都能上），BP 与总结里用的就是这套阵容。
   - **对局模式**：`玩家 vs 玩家`（两边都你按）、`玩家 vs AI`（你选一支队伍，整场跟着它走，AI 替你对面出牌）、`AI vs AI`（两边 AI 自己打，可以暂停/加速观战）。
   - **不再选红/蓝边**：BO3 / BO5 会换边，你整场跟随同一支队伍——它这局在蓝你就坐蓝，下局在红你就坐红；输掉一局后由败方选边，AI 选边时会参考该队本季红/蓝两边的真实胜率（`TEAM_SIDE`）。
   - **AI 风格**：`运营流`（先抢版本强度与体系收益）、`节奏流`（优先强势期与对线压制）、`混合`（蓝方运营、红方节奏）。
   - AI 每次出手都会在 BP 页的「AI 的 BP 思路」面板里写清这一手为什么 ban / 为什么选（体系收益、位置与选手、克制关系、版本热门），不是只给结果。
   - **解说席**：BP 时每手都会有一条点评，带 `妙手 / 好手 / 常规 / 一般 / 疑问手` 评级与理由（拆没拆组合、ban 有没有踩在对面已锁位置上、上一局痛点在不在），可随时开关。
   - **AI 按职业赛的路子出牌**：英雄能打哪几个位置由 2159 局职业比赛的实际上场位置统计（`js/data/profiles.js` 的 `PRO_ROLES`）决定，近几年没打过中单的英雄不会被塞到中单；每队还有主副风格（Gen.G 玄武大阵、BLG/TES/IG 强压冲阵、KT 强开、NS 消耗），AI 优先补体系核心件与队伍舒适英雄，一抢拿摇摆位、辅助晚亮、二轮再拿克制，ban 位会读两边的被 ban/爱 ban 数据，并且按位置算账、跨局记仇。
2. **BP**：20 手标准顺序（6 ban → 蓝1 红2 蓝2 红1 → 4 ban → 红1 蓝2 红1），红蓝方顺序不同；支持搜索、按位置/标签筛选、★ 招牌英雄提示、系统推荐、AI 代打、撤销、放弃本局；鼠标停在英雄格上会弹出该英雄的**原画预览**。已经出场的选人卡上会直接显示**选手头像 + 名字**，一眼看出谁拿了什么英雄。右侧解说席逐手点评。
3. **阵容整理**：可拖动英雄卡换位置、点两个位置交换、直接在每行下拉里换选手（含替补与自由选手），确认后进入分析。
4. **分析**：最上方是**双方阵容原画**（五个位置各一张英雄原画，带英雄名与选手名），接着是 **BP 质量面板**（双方阵容评分 / 纸面实力、体系标签、下路组合与本赛季胜率、最大结构缺陷，以及这局 BP 折算的胜率百分点），下面接分路对位差值、13 个阵容维度对比（前排/开团/控制/爆发/持续输出/消耗清线/后期/前期/续航/分推 + 组合协同/对位克制/版本契合）、解说式胜率预测、合理性点评。
5. **模拟**：45 条左右的整局解说文案（BP 复盘 → 开局视野 → 野区 → 一塔 → 换线 → 小龙 → 团战 → 大龙 → 龙魂 → 高地 → 收尾 → 赛后复盘），带时间戳与实时击杀比；顶部是**经济走势图**（蓝/红面积曲线 + 潮虫/先锋/小龙/龙魂/大龙的时间点标记）与资源条，右侧是**伤害占比 / 参团率对位对比**、双方选手数据表（含伤害占比条、参团率与 S–D 评分），下面是**网友评论**（按「好评 / 毒舌」和红蓝方筛选，挑表现最两极的选手开麦）、本局总结与**本局 MVP 卡**。
6. **MVP 界面**：一局结束后自动弹出 MVP 大图界面——**所用英雄的原画背景 + 扫光与暗角**、选手头像、**外号**、英雄图标/名称/称号、KDA、S–D 评分与伤害占比圆环、**成就徽章**（伤害王 / 评分第一 / 击杀王 / 零阵亡 / 团战核心 / 大场之王）、伤害占比与参团率进度条、六项数据、一句 MVP 评语 + 一句相关梗，以及**同队五人的对比小卡**（英雄、KDA、评分，MVP 高亮）；可点「继续」关闭，也可以点侧栏 MVP 卡再看一次。
7. **下一局**：败方选边（AI 替败方选时按该队红/蓝胜率），你整场跟着同一支队伍换边；系列赛结束显示冠军、比分与逐局结果，并给出**大场 MVP（SERIES POM）**——按单局评分、胜场、单局 MVP 次数、场均伤害占比与参团率综合选出；`玩家 vs AI` / `AI vs AI` 还会额外显示 **BP 对局 PK**（两边平均阵容分与胜负归因）和 **AI 的 BP 记录**（每局出了多少手 pick / ban）。

## 全局 BP（无畏征召）口径

- 一场 BO3 / BO5 内，**前面小局被选用的英雄，双方都不能再选**（本局开始前会显示「本大场已锁 N 个」，网格里已锁英雄灰化）。
- **禁用不继承**，每局重置（与 Riot Fearless Draft 一致）。
- 想看更狠的规则，可开「硬核模式：禁用也继承」——此时 ban 也会进全局池。
- 不做换手/拍卖/复选等额外规则，按现行职业赛 BP 顺序执行。

## BP 是怎么算的（数据驱动）

不是看纸面评分拍脑袋。胜率与评分来自两部分：

- **纸面实力（约 30%）**：五个位置选手评分的加权（中单/下路权重略高），代表「硬实力差」。
- **阵容合理性（约 70%）**：体系识别（前后排团战 / 冲阵突脸 / 消耗拉扯 / 抓单秒人 / 边路分带 / 速推压制 / 后期双核 / AOE 连招 / 反手拆团 九种，按英雄标签判定完成度）+ 下路组合强度与**本赛季真实胜率**（如霞洛 17 局 64.7%、卢米 69 局只有 33.3% 会被标的「版本陷阱」）+ 同位置对位克制（塞拉斯偷牛头/纳尔大招、波比断位移、风女莫甘娜拆团等 200 条）+ 版本强度（2025–2026 BP 率与胜率，旧赛季降权）+ 伤害结构/前排/开团/控制缺口。

最终胜率 = 纸面差 + 阵容评分差 的加权 sigmoid；**硬实力差 30 分以上会被放大成「几乎无法用 BP 逆转」，20 分左右仍可被好 BP 翻盘**。分析页会直接写出这局 BP 折算了多少个百分点。

AI 也吃同一套数据：ban 按版本 BP 率 + 对手招牌 + 对手体系缺口 + 能克制我方已选英雄的点；pick 按位置契合 + 选手招牌 + 版本强度 + 组合协同 + 对位克制 + 体系完成度，并在敌方体系成型后从「见招拆招」表里拿解（对面冲阵就摸风女/波比/塔里克，对面消耗就摸索拉卡/希维尔，对面大肉就摸薇恩/克格莫/格温），同时保证五个英雄一定能摆满五个位置。

**职业化的那一层在 `js/core/aibp.js` + `js/core/style.js` + `js/data/profiles.js`**：

- **职业分路硬约束**：`StyleDB.proData(id)` 只认真实职业样本（`PRO_ROLES`，1534 局能对上 24 队的场次里的位置占比），AI 绝不把英雄放到职业赛没打过的位置；无职业样本的英雄（小鱼人、卡特、提莫等）AI 直接不选。
- **战队风格**：`STYLES` 定义 9 套体系（玄武大阵 / 前中期强压 / 冲阵切后排 / 强开连招 / 消耗拉扯 / 后期双核 / 四保一 / 边路分带 / 运营控图），`TEAM_STYLE` 给 24 队配了主副风格、侵略性与舒适英雄（Gen.G 玄武大阵、T1 运营控图、HLE/BLG 前中期强压、TES/IG 冲阵、KT 强开、NS 消耗…）。AI 的体系骨架、位置标签、核心英雄都从这里加权。
- **抢/ban 优先级**：一抢（step 6）优先摇摆位与队伍第一顺位常用英雄，辅助和单一定位英雄降权；二轮与最后一手才对位克制；ban 位除了版本和绝活，还读 `TEAM_PROFILES` 的 `topBanned`（对手最常被 ban＝最舒服的点）与 `topBans`（自己队习惯 ban 谁），同时避免 ban 自家招牌。
- **顺序合理性**写在 `aibp.js` 的 `evalPick` 里：`firstOverall/early/last` 三种语境用不同权重，`why` 里会明确写「这手是一抢，先拿摇摆与舒适区」「这手是二轮，专门 counter」。
- **位置感知的 ban**（`evalBan`）：对面某位置已经锁好（`filledRoles` + `proRoleKeys` 判定）还往那丢 ban 会 **-5.6**，转去踩还没补的坑；对面亮了两手以上，拆组合（`META.synergy ≥ 4`）给到 +5.2；还会算「按了两次对面一次没拿」和「上一局对面赢在这手」，所以二三局不会照抄第一局。
- **阵容底线**（`evalPick`）：最后两手补前排（无 front/engage 时 +3.0）、补 AP（缺法术伤害时 +2.6）、后排三个脆皮时降权；体系反制走 `ARCH_TAGS`（对面想团战就补强边线/反手，对面消耗就补强开）。
- **红蓝边数据**：`TEAM_SIDE` 存每队本季红/蓝两边的场次与胜率，`analysis.js` 会把它折算成小幅 `sideEdge`，并在分析页写出「某队本季在蓝方 N 场 X%」的提示。

### 解说席与 BP 复盘

- `js/core/caster.js` 在 BP 过程中逐手给评价：`pickLine` / `banLine` 会结合选手招牌、队伍 ban/pick 习惯、体系缺件、组合拆解、版本 ban 率、对位克制与**跨局记忆**，最后用 `gradeOf` 跟当前最优解比出一个 `妙手 / 好手 / 常规 / 一般 / 疑问手` 的评级；面板可开关（`#btn-caster` / 首页「解说模式」）。
- 想按比赛复盘 BP，看 `docs/lpl-2026-split3-playoffs.md`：从 2026 LPL 第三赛段季后赛 55 局真实 BP 统计出 ban/pick 率、红蓝边、各系列赛比分、与常规段相比的优先级变化（蔚/魔腾被大幅提上来，波比/伊泽瑞尔被放掉），以及从这些局里复出来的 5 条博弈关键点。生成脚本 `_tools/poreport.mjs`，换数据可重跑。

数据由 `_tools/buildstats.mjs` 从 `_tools/gs16full.json`（`_tools/scrape16full.mjs` 抓取的 gol.gg 全部 S16 赛事单局页）与 `_tools/gs25.json` 聚合，结果写进 `js/data/prostats.js`（含 `PROSTATS.po` 季后赛子集）；战队画像与红蓝边由 `_tools/buildprofiles.mjs` 写进 `js/data/profiles.js`。体系/组合/克制/强势期的知识库在 `js/core/meta.js`，想改 BP 理解直接改这几个文件。

## 改数据 / 自定义

- 界面上「编辑选手数据」：按战队改位置与五项数值、擅长英雄（可填中文名或英文 ID，逗号分隔），改动存 localStorage，可一键恢复默认。
- **新增选手**：点「＋ 新增选手」，起名字、选位置，默认数值 78，之后随便改；自建选手带「自建」标记。编辑器上方还有一条**快捷新建表单**：填选手 ID、选队伍、选位置、填擅长英雄（中英文都行，英文 ID 会自动转成英雄），点「建立」直接进队。
- **转会**：编辑器每个选手行有「转会」按钮，选目标队伍就能整条挪过去（照片、数值、英雄池跟着走），首页与整理页立刻刷新。转去「★ 自由选手池」等于下放，任何队伍都能签。
- **自由选手池**：编辑器队伍下拉里有「★ 自由选手池」——真实选手点「转池」就能脱离原队进来，自建选手也可以放这里；池里的选手在首页和整理页的下拉里带「·自由」标记，**任何队伍都能上**，想组梦之队就往一队里塞。
- **新增队伍**：点「＋ 新增队伍」，填队名、缩写、主色、辅色，马上出现在首页下拉里，再点「换队标」给它传个队标图。
- **换头像**：编辑器每行点「头像」直接传图（会自动裁成 200×200 存进浏览器，存在 localStorage 里）。
- 直接改文件：`js/data/players.js`（选手）、`js/data/champmeta.js`（英雄位置/伤害/标签）、`js/data/teams.js`（战队）。
- 改图片文件：头像放 `assets/players/`，再改 `js/data/photos.js` 里 `'队名|选手名'` 对应的路径；没有照片的选手用 `assets/players/auto/*.svg` 生成头像（战队配色 + 姓名首字 + 队标缩写），改 `_tools/mkavatar.mjs` 可重新生成。
- 英雄原画在 `assets/champ/art/<英雄英文ID>.jpg`，来自 Riot Data Dragon（`_tools/champart.mjs` 可重新下载或换版本）；方框图/载入图在 `assets/champ/tile|splash/`。

## 已知限制

- 37 名 LPL 选手（多为中文 ID）在没有公开资料的页面上，用战队配色的字母/首字头像替代；你可以在编辑器里给他们传自己的图。真实照片来自 Liquipedia，英雄原画/方框图/载入图来自 Riot Data Dragon（都是个人学习用途）。
- 自建队伍、自建选手、上传的头像都存在浏览器 localStorage 里，换浏览器/清缓存会丢；想长期保存可以把 `js/data/players.js`、`js/data/teams.js`、`js/data/photos.js` 改到文件里。
- 模拟是文本解说 + 数值推导，不是真实比赛引擎；解说文案有随机分支，同一局重开结果可能不同。
- 阵容数据取自 2026 赛季 LPL / LCK 巡回赛页面（如 T1 下路 Peyz、HLE 为 Zeus/Kanavi/Zeka/Gumayusi/Delight），赛季中转会可能已过期。
- 只做了桌面布局，窄屏可用但未专门适配手机。
- 实战数据覆盖 gol.gg 上 2025 + 2026 赛季的 LPL/LCK/LEC/MSI/Worlds/First Stand/德杯等 24 个赛事（2159 局），但**只统计能对上站点 24 支战队的场次**做战队画像，对阵欧美队的国际赛局会进英雄统计、却不会进战队画像；下路组合与对位的样本量在十几到几十局，样本小的组合容易偏差。
- 没有选手逐局数据（gol.gg 免费页不给），所以「局内表现」是用选手评分 + 英雄/体系强度间接体现的，不是真实 KDA 统计。
- 职业分路统计里仍有少数英雄在 2159 局中没出过场（提莫、蛮王、卡特一类），AI 会直接跳过它们；你手动选仍然可以，只是不会吃到职业分路加权。
- 选手评分是按「队伍本季战绩 + 位置形状 + 明星系数」校准的相对值，不是官方评分；觉得谁高了低了，编辑器里改完点「保存修改」即可。
- 评论里的黑称是照着虎扑/抗压吧的说法收的，只在选手打得差时按数据触发，属于节目效果，不代表真实评价。
